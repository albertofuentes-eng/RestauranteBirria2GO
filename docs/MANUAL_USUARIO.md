# Manual de usuario (resumen)

- **Mesero**: Mesas (abrir orden, cambiar estado) → Órdenes (agregar platillos, entregar los que cocina deja listos) → Reservas (registrar con platillos, atender cuando llega el cliente).
- **Cocina**: tablero con columnas por estado; avance cada platillo (o toda la orden) con los botones. Se actualiza solo.
- **Cajero**: Caja → elegir método de pago → Cobrar; se muestra el comprobante imprimible con promociones e impuestos aplicados.
- **Administrador**: Configuración (empresa, logotipo, moneda, impuestos, parámetros), Catálogos (zonas, estados, tipos de orden, métodos de pago, monedas), Menú, Promociones, Usuarios, Roles y permisos, Bitácora y Reportes.
- **Bitácora**: filtre por usuario, acción, tabla y fechas; cada fila muestra valores anteriores y nuevos.
