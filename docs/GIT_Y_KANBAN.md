# Git y Kanban
## Git
Crear un repositorio público, agregar este proyecto y trabajar con ramas por módulo. Cada integrante debe hacer commits propios y descriptivos; no simular historial ni concentrar todo en un commit final.
## Tablero sugerido
Columnas: Backlog, Por hacer, En progreso, En revisión, Terminado. Tarjetas: BD/DER, seguridad, configuración, mesas, menú, preórdenes, órdenes para llevar, cocina, promociones, caja, reportes, auditoría, pruebas, documentación y despliegue. Asignar responsables reales y fechas.
